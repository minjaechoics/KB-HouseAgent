# 내려받은 원천데이터

공공 API, 이용 권한을 확인한 외부 데이터, 사용자가 직접 내려받은 파일을 두는 디렉터리입니다.
원천데이터는 크기와 재배포 조건 때문에 Git에 포함하지 않습니다.

주요 하위 디렉터리:

- real_estate: 국토교통부 실거래가, HUG 통계 등
- facilities: 병원, 약국, 음식점, 카페, 마트 등 공공시설 통합 캐시
- safety: CCTV, 비상벨, 경찰·소방 관련 공개 데이터
- finance_policies: 청년 주거 금융정책
- finance_products: 금융기관 상품 자료

README의 데이터 준비 절차와 각 다운로드 스크립트를 사용해 복원할 수 있습니다.
