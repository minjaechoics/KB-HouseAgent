# 공공 부동산·지역시장·공간 데이터 통합 설계

## 결론

서비스는 현재 거래 가능한 실매물 피드를 보유하지 않는다. 따라서 지도 후보는 **분석용 합성 후보**로 유지하고, 가격·시장·위치의 근거만 공식 공공데이터로 강화한다. 합성 후보를 실제 매물처럼 표시하거나 공공시설 주소에 주택이 존재한다고 주장하지 않는다.

## 1. 국토교통부 실거래가

승인된 REST API 중 주거 의사결정에 직접 필요한 다음 계열을 사용한다.

- 아파트 매매 및 아파트 매매 상세
- 오피스텔 매매·전월세
- 단독·다가구 매매·전월세

원천 CSV는 `data/downloaded/real_estate`에 보존하며 SQLite의 `property_price_observations`에는 취소 거래 여부, 거래월, 시군구 코드, 주택유형, 거래유형, 가격·보증금·월세, 면적, 층, 건축연도를 정규화한다. 아파트 상세 API의 단지 일련번호, 도로명, 본번·부번, 매수·매도자 유형, 중개지역 등은 `rtms_transaction_details`에 별도 보존한다.

리포트의 실거래 그래프는 개별 호가가 아니라 동일 시군구·주택유형·거래유형의 신고 실거래 월 집계다. 취소 거래는 제외한다.

## 2. 한국부동산원 R-ONE

R-ONE `SttsApiTbl`의 통계표 메타데이터 738건을 모두 `rone_stat_tables`에 저장한다. 관측값은 다음 25개 핵심 통계표의 최근 30개월을 `rone_stat_observations`에 증분 저장한다.

- 주택종합·아파트·연립/다세대·단독주택·오피스텔의 매매/전세/월세 가격지수
- 아파트·주택종합의 매매/전세/월세 수급동향
- 아파트 평균 매매·전세·월세 가격과 평균 매매가격 대비 전세가격

상세 리포트에서는 선택 후보의 시도·시군구, 주택유형, 거래유형으로 가장 가까운 R-ONE 분류를 선택한다. 화면에는 최신 가격지수, 전월 지수 변화, 수급지수, 기준시점을 같이 표시한다. 지수는 개별 매물 가격이 아니라 기준시점 대비 지역 시장의 상대 변화다.

## 3. V-World 전기차 충전소 활용모델

V-World의 2023년 7월 전기차 충전소 활용모델은 OpenLayers/V-World 지도 위에 공공데이터포털 `EvInfoServiceV2` 충전기 데이터를 시각화한다. 본 서비스는 같은 출처 구조를 서버 도구로 재현한다.

1. 별도 승인된 `EV_CHARGER_SERVICE_KEY`로 충전기 스냅샷을 수집한다.
2. `ev_chargers`에 충전소명, 충전기명, 주소, 좌표, 충전방식, 상태와 수집시점을 저장한다.
3. 사용자가 자가용·전기차를 선택한 경우에만 선택 주택 반경 1.5km를 검색한다.
4. 충전기 수, 수집시점 충전 가능 수, 가까운 충전소를 거리순으로 보여준다.

국토교통부 RTMS 승인키는 EvInfoServiceV2 사용 권한을 대신하지 않는다. 해당 서비스 키가 없을 때는 0건으로 꾸미지 않고 “별도 키/동기화 없음”으로 표시한다.

## 4. 합성 후보의 지도 위치 현실화

기존 `합성구·합성동·합성로` 문자열은 지도에서 검색되지 않고 좌표와 주소가 일치하지 않았다. 생성기 v6는 다음 방식으로 바뀌었다.

- 전국 공공 CCTV 원천의 도로명·지번 주소와 WGS84 좌표를 한 쌍의 위치 기준점으로 사용한다.
- 같은 시군구 안에서 기준점을 층화 표본추출하여 전국 252개 검색 지역에 분산한다.
- 법정동 코드 파일에서 실제 읍면동 이름과 코드를 같은 시군구 범위 안에서 배정한다.
- 공공주소가 없는 소수 지역은 `시도 시군구 읍면동` 수준의 실제 행정지명을 사용한다.
- 후보의 가격·면적·방수·권리관계·중개사 필드는 계속 합성값이며 실제 주소지의 건물 사실로 해석하지 않는다.

지도와 상세화면에는 “분석용 합성 후보·실제 거래 매물 아님·공공주소 기준 위치”를 항상 노출한다.

## 5. 2026-07-23 운영 스냅샷

- 분석 후보: 100,000건, 17개 시도·252개 시군구, 매매/전세/월세 균형 배분
- 아파트 상세 원천 CSV: 2026년 1~6월 전국 요청 결과 291,591행
- 아파트 상세 정규화 DB: 중복 신고 식별자를 합친 284,052건, 거래가 존재한 255개 법정 시군구 코드
- 전체 국토교통부 가격 관측: 931,929건
- R-ONE 핵심 통계 관측: 88,541건, 25개 통계표, 2024-02~2026-06

원천 행 수와 DB 행 수의 차이는 같은 거래 식별자로 재수집되거나 중복 신고된 행을 `INSERT OR REPLACE`로 멱등 정규화했기 때문이다. 거래가 없는 시군구·월 요청도 성공 요청으로 기록하므로 시군구 요청 수와 관측 시군구 수는 같지 않을 수 있다.

## 6. 운영 및 갱신

```bash
python scripts/download_rtms_apt_trade_dev.py --months 202606 --lawd-cd 11110
python scripts/sync_rone_market_data.py --months 30
python scripts/sync_ev_chargers.py
python -m src.data_augmentation.universal_generate --n-properties 100000
python -m src.db.build_db
```

운영 키는 `deploy/*.private.env`에만 두며 이미지·소스·API 응답에 포함하지 않는다. RTMS와 R-ONE은 예약 동기화가 실패해도 마지막 정상 스냅샷을 유지하고 오류를 출처 상태 API에 표시하도록 확장할 수 있다.
