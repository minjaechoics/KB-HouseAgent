## 1. 결론과 현재 적용 상태

이번 변경으로 다음 두 경로를 구현했다.

1. **계약 단위 실제 HF/HUG 라벨 재학습 경로**
   - 실제 계약별 정상/사고 라벨을 엄격히 검증한다.
   - 보증발급일 기준으로 과거 60% 학습, 다음 20% 확률보정·임계값 선정, 최신 20% 최종시험을 수행한다.
   - 로지스틱 회귀계수를 새로 학습한다.
   - Platt scaling과 isotonic regression 중 시간상 더 나중인 보정 표본에서 Brier score가 낮은 것을 선택한다.
   - 사고 누락과 오경보의 비용을 반영해 운영 임계값을 정한다.
   - 모델, 보정기, 임계값, 데이터 해시, 기간분할, 시험성능을 함께 저장한다.

2. **지금 즉시 적용한 실제사고 연구계수 이식 경로**
   - 로컬에 계약 단위 실제 원시라벨이 없으므로, 453,122건의 실제 보증계약과 22,601건의 사고를 분석한 HF 연구의 공개 계수를 이식했다.
   - 논문 표에 발급연도 통제계수가 생략되어 있어 원 절편을 그대로 확률로 사용하지 않았다. 현재 전세 매물 포트폴리오의 평균 예측확률이 연구 표본 관측률 `22,601 / 453,122 = 4.98784%`가 되도록 로짓 절편만 이동했다.
   - 사고 누락 비용 20, 오경보 비용 1이라는 현재 정책에서 베이즈 임계값은 `1 / (20 + 1) = 0.047619`이다.
   - 생성 매물 DB의 전세 33,333건을 이 모형으로 재점수화했다.

중요한 한계가 있다. 현재 적용본은 **실제 사고 라벨로 추정된 외부 공개계수의 transfer model**이지, 이 저장소 안에서 원시 HF/HUG 계약 레코드를 다시 적합한 모델은 아니다. HUG 공개 개별 대위변제 파일은 파일명과 공공데이터 안내서에서 합성데이터로 명시되어 있어 실제라벨 학습에서 제외했다. 계약 단위 실제 원자료를 확보하면 1번 경로가 외부계수 이식본을 대체한다.

## 2. 왜 공개 HUG 파일을 그대로 0/1 라벨로 학습하지 않았는가

보유 자료를 감사한 결과는 다음과 같다.

| 파일 | 단위 | 학습 사용 여부 | 이유 |
|---|---:|---:|---|
| `hug_subrogation_synthetic_20250731.csv` | 개별형 50,054행 | 제외 | HUG가 합성자료로 명시 |
| `hug_return_guarantee_accidents_by_region_20250831.xlsx` | 시군구 집계 | 개별계수 학습 제외 | 최근 3개월 사고건수·금액·사고율 집계 |
| `hug_return_guarantee_detail_20260228.csv` | 연도 집계 | 개별계수 학습 제외 | 연도별 사고건수·금액 2행 |
| `hug_return_guarantee_detail_status_20260331.csv` | 발급연월·유형·지역 집계 | 개별계수 학습 제외 | 보증 발급 건수·금액이지 계약별 사고결과가 아님 |
| `hug_jeonse_status_20250531.xlsx` | 피해주택 시군구·유형 집계 | 개별계수 학습 제외 | 피해결정 신청 주택 집계, 정상 대조군 없음 |

지역별 사고율을 각 지역의 모든 매물에 동일한 0/1 라벨처럼 복제하면 집계자료의 상관을 개인자료의 관계로 오인하는 생태학적 오류가 생긴다. 발급 건수와 사고 건수도 동일 코호트의 만기 관찰 결과가 아니면 단순 나눗셈을 할 수 없다. 특히 HUG의 `2025년 8월 최근 3개월 사고율 1.6%`와 HF 연구의 `만기가 도래한 발급계약을 2024년 12월까지 관찰한 사고율 약 5%`는 시간창과 모집단이 다르므로 서로 대체하지 않았다.

## 3. 라벨 정의와 검열 처리

HUG는 보증사고를 크게 다음으로 정의한다.

- 계약 종료 후 1개월이 지나도 임대인이 보증금을 반환하지 않은 경우
- 계약기간 중 경매·공매 후 보증금을 회수하지 못한 경우

정상화된 사고는 HF 연구처럼 사고에서 제외해야 한다. 아직 만기가 오지 않았거나 만기 후 30일이 지나지 않은 정상 행은 진짜 정상인지 알 수 없는 우측 검열 표본이다. `real_labels.py`는 이런 행을 음성 라벨로 학습하지 않고 제외한다.

실제 라벨 CSV는 다음 파일을 본떠 준비한다.

- `data/downloaded/real_estate/hug/actual_contract_labels.template.csv`
- `data/downloaded/real_estate/hug/actual_contract_labels.provenance.template.json`

provenance에는 다음이 반드시 필요하다.

- `data_classification = actual_contract_level`
- `contains_synthetic = false`
- 제공기관과 라벨 관찰종료일
- 라벨 정의
- 선택적으로 CSV SHA-256
- 데이터 이용권한과 비식별 처리 근거

입력기에 적용한 방어 규칙은 다음과 같다.

- 파일명에 `synthetic` 또는 `합성`이 있으면 즉시 중단
- `is_synthetic=true` 행이 있으면 즉시 중단
- 계약 ID가 없거나 중복이면 중단
- 지역별 건수 같은 집계 스키마는 필수 계약 컬럼 부족으로 중단
- 정상·사고 두 클래스가 모두 없으면 중단
- 금액은 만원, 금리는 `%p`, 라벨은 0/1로 고정
- 사고일·대위변제액은 결과와 비용 평가에만 쓰고 예측 피처에는 넣지 않아 누수를 차단

## 4. 피처와 공개 실제사고 계수

HF 연구는 2019년 1월부터 2023년 12월까지 발급되고 만기가 도래한 수도권 보증 453,122건을 2024년 12월까지 관찰했다. 전체 사고는 22,601건이었다. 구현은 논문 표 10의 전체모형 계수를 사용한다.

| 피처 | 계수 | 해석상 주의 |
|---|---:|---|

| 다주택 임대인 | +0.930 | 현재 생성매물에는 이 실측값이 없어 미상 0 처리 |
| 등록 임대사업자 | -0.037 | 보증 표본 선택효과가 포함될 수 있음 |

| 오피스텔 | +0.836 | 아파트가 기준범주 |

부채비율은 `(임대보증금 + 선순위채권) / 주택가격 × 100`으로 계산한다. 기존 코드가 경매 회수율 75%를 먼저 적용한 경험식과 다르며, 이번 모형은 논문 정의와 일치시키기 위해 별도 피처 계약을 사용한다.

선순위채권 계수가 음수라는 사실을 “선순위채권은 안전하다”로 해석하면 안 된다. 논문 표본은 보증가입 조건 때문에 선순위채권이 주택가격의 60% 이내로 제한되었고, 저자는 이 선택효과를 명시했다. 서비스의 설명문에서도 단일 계수의 인과 해석을 금지해야 한다.

## 5. 로컬 실제라벨 재학습 알고리즘

구현 위치는 `src/fraud_risk/train_actual.py`이다.

### 5.1 시간 분할

무작위 분할은 미래 시장국면의 레코드가 과거 학습에 섞일 수 있다. 보증발급일의 고유 날짜를 정렬하여 다음처럼 분리한다.

```text
과거 60%                다음 20%                 최신 20%
계수 학습       ->       확률보정·임계값       -> 최종 1회 시험
```

각 구간에 정상과 사고가 모두 존재하는지도 확인한다. 최종 시험구간은 모형·보정법·임계값 선택에 사용하지 않는다.

### 5.2 계수 학습

해석 가능한 이항 로지스틱 회귀를 사용한다.

1. 숫자 결측값을 학습기간 중앙값으로 대체하고 결측 지시자를 추가한다.
2. 학습기간 평균·표준편차로 표준화한다.
3. L2 정규화 로지스틱 회귀를 적합한다.
4. SMOTE나 임의 클래스 가중치는 기본적으로 쓰지 않는다. 그런 재표본화는 원래 사고 기저율을 바꾸어 확률을 왜곡할 수 있기 때문이다.

### 5.3 확률 보정

분류 순위가 좋다고 `0.10`이 실제 10%를 뜻하는 것은 아니다. 보정기간을 다시 시간순 절반으로 나누어 앞 절반으로 다음 두 보정기를 학습하고 뒤 절반 Brier score로 선택한다.

- Platt scaling: 원 확률의 logit에 다시 로지스틱 함수를 적합
- Isotonic regression: 단조 비감소 계단함수를 비모수적으로 적합

표본이 100건 미만이거나 사고가 10건 미만이면 isotonic 과적합을 피하기 위해 Platt를 사용한다. 선택 후 선택된 방법을 전체 보정기간에 다시 적합한다.

최종 시험기간에는 다음을 기록한다.

- ROC-AUC: 순위 분리력
- PR-AUC: 희소 사고 클래스 분리력
- Brier score: 확률 제곱오차
- log loss: 과도하게 확신한 오류에 민감한 확률손실
- ECE 10구간: 예측확률과 관측률 간 간격
- 운영 임계값에서 precision, recall, confusion matrix
- 관측 사고율과 평균 예측확률

### 5.4 비용 기반 임계값

보정된 사고확률을 `p`, 사고를 놓치는 비용을 `C_FN`, 정상 매물을 위험하다고 표시하는 비용을 `C_FP`라 하면, 비용이 상수일 때 위험조치를 취하는 베이즈 임계값은 다음과 같다.

```text
t = C_FP / (C_FP + C_FN)
```

현재 정책은 `C_FN=20`, `C_FP=1`이라 `t=0.047619`이다. 실제 라벨 재학습 경로에서는 이론값만 고정하지 않고 보정기간의 모든 후보 임계값을 훑어 `FN × C_FN + FP × C_FP`가 최소인 값을 선택한다.

20:1은 논문에서 추정된 사회적 비용이 아니라 현재 제품의 보수적 정책값이다. 운영자가 민원·점검비용·보증금 손실·기회비용을 산정한 뒤 CLI 옵션으로 바꿔야 한다. 비용값이 바뀌면 계수를 다시 학습할 필요는 없지만 임계값은 다시 선택해야 한다.

```powershell
python -m src.fraud_risk.train_actual `
  --labels data/downloaded/real_estate/hug/actual_contract_labels.csv `
  --provenance data/downloaded/real_estate/hug/actual_contract_labels.provenance.json `
  --false-negative-cost 20 `
  --false-positive-cost 1 `
  --apply
```

## 8. 운영 모니터링과 재학습 조건

월별로 다음을 저장해야 한다.

- 점수분포 PSI 또는 Wasserstein distance
- 피처 결측률과 범주 미등장률
- 만기가 도래한 코호트의 관측 사고율
- Brier score, calibration slope/intercept, reliability diagram
- 임계값 기준 오경보·누락 및 실제 비용
- 지역·주택유형별 성능; 단, 소표본 셀은 공개하지 않음

다음 중 하나면 재보정 또는 재학습한다.

- 평균 예측확률과 관측률 차이가 사전 합의 범위를 초과
- calibration slope가 1에서 크게 이탈
- 새로운 보증가입 요건이나 주택가격 산정기준 시행
- 금리·가격 급변으로 최신 코호트 PR-AUC/Brier가 악화
- 신규 지역·주택유형 비중이 학습범위를 벗어남

## 9. 안전·해석 원칙

- `fraud_score`의 정확한 뜻은 **보증가입 표본 정의에 조건부인 보증사고 추정확률**이다. “전세사기 범죄자일 확률”이 아니다.
- 낮은 점수는 등기, 신탁, 체납, 선순위임차인, 건축물대장 확인을 생략해도 된다는 뜻이 아니다.
- 보증가입 가능 여부를 별도 확인해야 한다.
- 생성 매물 자체는 실제 광고가 아니며 위치와 권리관계가 합성임을 UI에 계속 표시해야 한다.
- 공개계수 이식본은 모델카드의 `label_source_status=actual_labels_external_published_coefficients`로 표시한다. 로컬 실제라벨 재학습이 성공한 경우에만 `actual_contract_level_verified`로 바뀐다.
