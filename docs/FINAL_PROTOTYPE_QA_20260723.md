# 청년 주택 의사결정 도우미 최종 시제품 구현·검증 기록

작성일: 2026-07-23  
운영 주소: `http://52.79.138.208/gui` (Basic 인증 필요)

## 1. 최종 사용자 흐름

1. 시작 화면에는 입력 폼을 노출하지 않고 `시작하기` 버튼만 둔다.
2. 시작 화면 다음 단계에서 사용자·주거·금융 적격성 정보를 입력한다.
3. 초기 조건의 교집합으로 매물 후보를 검색한다.
4. AI 조건은 초기 교집합 안에서만 후보를 좁히며, 사용자가 버튼으로 승인한 뒤 적용한다.
5. 매물을 선택하면 예산, 자산 시뮬레이션, 치안, 생활 편의, 계약 안전 리포트를 제공한다.
6. 자산 시뮬레이션에서 금융상품 카드를 누르면 상품별 순자산 경로가 색상별로 겹쳐 표시된다.

## 3. 금융상품별 자산 변화 시뮬레이션

### 3.1 비교 원칙

동일한 매물, 소득 증가율, 물가상승률, 금융자산 수익률, 생활비, 집값 경로를 고정하고 금융상품만 교체한다. 비교 결과에는 다음 값을 포함한다.

- 실제 사용 대출액
- 미조달 금액
- 적용 금리와 금리 출처
- 초기 월 상환액
- 누적 이자
- 누적 상환 원금
- 연도별 잔여부채
- 연도별 순자산
- 종료 시 부채와 순자산
- 상환 완료 연도와 나이

### 3.2 매매대출

매매대출은 상품 문서에서 대출기간을 추출하고, 기간을 찾지 못하면 30년을 사용한다. 월 상환액은 원리금균등상환 공식으로 계산한다.

```text
월상환액 = 원금 × 월금리 × (1 + 월금리)^개월수
           / ((1 + 월금리)^개월수 - 1)
```

매월 이자를 먼저 계산하고 나머지를 원금 상환으로 처리한다. 따라서 시뮬레이션 경로의 부채는 매년 감소하며, 상환액과 이자가 현금성 자산에 동시에 반영된다.

### 3.3 전세·월세 대출

전세·월세 대출은 거주 중 이자를 납부하고, 시뮬레이션 종료 시 반환받은 보증금으로 대출 원금을 상환하는 조건부 가정을 사용한다. 종료 경로에서는 보증금 자산과 부채를 동시에 정리하고 남은 금액만 현금성 자산으로 이동한다.

### 3.4 공개 금리가 없는 상품

`rate_pct`가 없으면 `rate_max_pct`, `rate_min_pct` 순서로 사용한다. 어느 금리도 없으면 보수적 기본금리 가정을 적용하고 UI에 별도 경고를 표시한다. 실제 실행금리는 은행 심사 결과로 다시 확인해야 한다.

## 4. 최종 의사결정 체크리스트

매물 리포트는 다음 여섯 축을 한 화면에서 확인한다.

1. 자금조달: 자기자금, 공개 상품 한도, 미조달 금액
2. 상환 스트레스: 보수적 순자산 경로와 월 상환액
3. 통근·생활비: 직장·학교·자주 가는 곳의 교통비 및 항목별 생활비
4. 계약 안전: 보증 가능성, 등기·압류, 임대인 세금 증빙
5. 시장·환금성: 신고 실거래 시계열, 지역 가격·수급 통계, 관련 뉴스
6. 주변 환경: 공공 CCTV·비상벨과 지도 API의 경찰·소방·생활 편의시설

이 체크리스트는 계약 승인 판정이 아니라 누락된 검증 항목을 드러내는 용도이다.

## 5. 오류와 디버그 정보 노출 방지

- HTTP 상태·서버 예외명·외부 사업자 오류 본문을 사용자 화면에 직접 표시하지 않는다.
- 네트워크·입력·세션·외부 API 문제를 사용자 행동 중심의 문장으로 변환한다.
- 전역 JavaScript 오류와 Promise 오류도 일반 안내 문장으로 처리한다.
- RAG 디버그 패널은 유지하되 API 키, 토큰, 비밀값, 스택, 외부 오류 본문과 상태코드를 제거한 뒤 표시한다.
- 서버 로그에는 진단 정보를 남기고 사용자 UI에는 원시 예외를 노출하지 않는다.

## 8. 알려진 운영 제약

- `http://52.79.138.208` 접속은 KAIST 네트워크의 DLP 정책에서 `k-dpms.kaist.ac.kr` 차단 화면으로 전환될 수 있다. 이는 앱 장애가 아니라 출발 네트워크의 HTTP 차단이다.
- 안정적인 외부 사용을 위해서는 도메인과 HTTPS 인증서를 연결하는 것이 권장된다.
- 금융상품 적격성은 공개 조건 기반 1차 판정이다. CSS, DSR, LTV, 담보평가, 보증서, 신용평가는 금융기관 최종 심사가 필요하다.
- 합성 후보는 실매물로 표시하지 않는다. 승인된 실매물만 실매물로 표시한다.
