## Ⅰ. 문제 정의 (3장) — 탐구 여정 구조

세 슬라이드를 "① 청년에게 물었다 → ② 전문가에게 확인했다 → ③ 시장을 검증했다"
하나의 조사 흐름으로 구성한다. 슬라이드마다 **🔍 한 것 → 💡 알게 된 것 → ➡ 그래서**
순서를 반복해서, 마지막에 세 갈래가 한 지점(다가구주택의 숨은 리스크)으로
모이는 걸 보여준다. 각 슬라이드 상단에 진행 표시(① → ② → ③)를 넣으면 좋다.

### 슬라이드 1 — ① 청년 30명에게 직접 물었다

**헤드라인**: 청년들은 정보를 몰라서가 아니라, 무엇을 믿어야 할지 몰라서 불안해했다

- 🔍 **한 것**: 청년 30명 심층 인터뷰

| 페인포인트 | 응답 비율 |
|---|---|
| 전세사기 불안·리스크 검증 한계 | **90.0% (27명)** |
| 정보 파편화로 인한 피로감 | 83.3% (25명) |
| 임장·실물 확인의 부담 | 70.0% (21명) |
| 의사결정 복잡성(전/월세 선택 장애) | 63.3% (19명) |

- 💡 **알게 된 것**: 네 가지 고민을 정보수집→해석→예측→결정 4단계로 정리해보니,
  유독 "예측"(전세사기 위험 판단) 단계에 불안이 압도적으로 몰려 있었음(90.0%)
- 대표 인용: "전세사기가 무서운데, 제가 모르는 위험 요소가 있을까 봐 불안해요."
- ➡ **그래서**: "무엇이 구체적으로 위험한지" 다시 물으면 다들 명확히 답하지
  못함 — 실무 전문가에게 직접 확인하기로 함
- (하단 작게) 조사 개요: 청년 30명 대상 심층 인터뷰, [모집 방식·시기 기입]

### 슬라이드 2 — ② 현직 공인중개사에게 확인했다

**헤드라인**: 청년들이 막연히 느끼던 불안의 실체는 "다가구주택 선순위보증금"이었다

- 🔍 **한 것**: 현직 공인중개사 자문
- 💡 **알게 된 것**: 청년 인터뷰의 "막연한 불안"을 전문가가 구체적 리스크로 명확히
  지목 — "다가구주택은 구분등기가 없어 선순위보증금을 시장에서 확인할 방법
  자체가 없다"

| | ① 청년 30명 인터뷰 | ② 공인중개사 자문 |
|---|---|---|
| 근거 유형 | 당사자 체감(정성) | 실무 전문가 검증 |
| 확인된 것 | 예측 단계 불안 90.0% | 청년이 실제로 가장 놓치는 위험 지점 특정 |

- 서로 다른 두 출처가 독립적으로 같은 지점(예측 단계, 다가구주택)을 가리킴 →
  문제 정의의 신뢰도를 이중으로 확보
- ➡ **그래서**: 이 문제가 이미 시장에서 풀렸는지 확인하기 위해 기존 서비스를
  직접 써보기로 함

### 슬라이드 3 — ③ 기존 서비스를 직접 써봤다

**헤드라인**: 기존 서비스는 조건을 지키지 못했고, 다가구·원룸은 아예 다루지
못했다

> 발표 톤 주의: 특정 서비스를 깎아내리는 어조가 아니라 "실사용 테스트로 확인한
> 업계 공통의 한계"로 담담하게 서술한다.

- 🔍 **한 것**: 기존 부동산 검색 서비스(챗봇 포함) 실사용 테스트
- 💡 **알게 된 것**: 반복 확인된 두 가지 실패 패턴
  1. **위치 인식 실패**: 실제로 통용되는 랜드마크 질의를 반복적으로 인식하지
     못하고 동일한 안내 메시지만 재반환 (스크린샷 A)
  2. **대화 문맥 유실**: 사용자가 새로 준 위치 조건을 반영하지 못하고, 대화
     초반에 언급됐던 지역 기준으로 계속 결과를 반환 (스크린샷 B)
  - 공통적으로 **원룸·다가구주택 매물 커버리지도 약함**
- ➡ **그래서**: 세 번의 조사(①청년 ②전문가 ③시장)가 가리키는 지점은 하나 —
  "다가구주택의 숨은 리스크를, 조건을 지키는 신뢰 가능한 방식으로 풀어야 한다"

(스크린샷 삽입: A. 위치 인식 실패 반복 / B. 문맥 유실로 엉뚱한 지역 응답)

**세 갈래 요약 (슬라이드 하단 또는 별도 정리 다이어그램)**

```
① 청년 인터뷰 ──┐
② 전문가 자문  ──┼──> 다가구주택 리스크는 실재하고, 아직 아무도 안 풀었다 ──> 솔루션 개요
③ 시장 테스트  ──┘
```

## Ⅱ. 솔루션 개요 (3장)

### 슬라이드 4 — 솔루션 한 줄 요약

**헤드라인**: 다가구주택 리스크와 금융상품을 반영해, 청년 주거·자산 의사결정
4단계 전부에 하나의 에이전트로 대응한다

- 프로젝트 제목 정식 소개
- 4단계(정보수집·해석·예측·결정) 각각에 대응하는 기능을 한 장에 매핑

### 슬라이드 5 — 핵심 기능 2가지

**헤드라인**: 사용자는 조건을 검색하거나, AI에게 직접 물어 추천받을 수 있다

- ① 조건 검색 — AI가 임의로 검색 범위를 넓히지 않는, 승인 기반의 신뢰 가능한 검색
- ② AI 매물추천·상담 — 질문에 답하거나(qa_*) 목표를 주면 능동 추천(goal_*)
- (앞 슬라이드의 위치인식·문맥유실 실패 사례와 대비되는 화면 캡처를 함께 배치하면 설득력 ↑)

### 슬라이드 6 — 사용자 여정 한 장

**헤드라인**: 검색부터 리포트, AI 상담까지 하나의 흐름으로 이어진다

- 검색 → 조건 승인 → 매물 선택 → 진단 리포트(재정·동네·위험·총평) → AI 상담
- 실제 화면 캡처 4~5컷으로 구성

## Ⅲ. 전체 아키텍처 (2장)

### 슬라이드 7 — 시스템 레이어 구조

**헤드라인**: AI는 계획만 세우고, 계산은 검증된 코드가 수행한다

```
모바일/웹 UI
  ↓
FastAPI 서비스 계층
  ↓
Agentic Orchestrator (Planner → Text-to-SQL → Tool 실행 → Grounded Synthesis)
  ↓
결정적 도구·모델 (RDB, 지도, 위험모델, 시뮬레이션, 최적화)
  ↓
데이터·감사 (SQLite, decision_run_id 감사 추적)
```

- "하네스 엔지니어링" 용어 소개: 프롬프트 엔지니어링이 아니라 LLM을 감싸는
  구조(scaffold) 설계

### 슬라이드 8 — 요청 한 번의 생명주기

**헤드라인**: 모든 판단은 decision_run_id 하나로 재현 가능하다

- 사용자 입력 → Planner(의도·슬롯) → 조건 승인 → Text-to-SQL(3중 방어) →
  도구 실행 → Grounded Synthesis → 감사 저장
- SQL 방어 계층(허용 테이블·읽기전용 연결·authorizer) 요약 한 줄

## Ⅳ. 기술 (4장, 개별 요소 딥다이브)

### 슬라이드 9 — 할루시네이션 비교 실험

**헤드라인**: 구조 분리 없이 LLM에 맡기면 환각이 발생하고, 하네스 구조는 이를
실측으로 줄인다

- 실험 설계: 자유형 LLM 응답 vs 하네스(계획-실행 분리) 응답 비교
- 결과 수치 삽입 (민재님 실험 결과값)

### 슬라이드 10 — 확률적 리스크 모델링

**헤드라인**: 전세사기 위험을 하나의 점수로 뭉개지 않고, 다가구 선순위보증금까지
확률로 정량화했다

- 위험모델 3종: 전세사기 위험도(HUG·HF 학습) · 집주인 총자산비율 · 선순위
  임차보증금(다가구 전용)
- 문제정의 슬라이드 2의 "★ 예측 단계 사각지대"를 여기서 회수

### 슬라이드 11 — 생애자산 시뮬레이션 + MILP 파레토 최적화

**헤드라인**: 매물 선택은 단일 정답이 아니라 자산·부담·안전의 트레이드오프이며,
파레토 최적해로 제시한다

- 10,000경로 Monte Carlo 생애자산 시뮬레이션
- 매물×금융상품×대출액 MILP, 5개 대표 성향(내 성향/자산성장/월부담/안전/통근)

### 슬라이드 12 — 작업 DAG 스케줄링

**헤드라인**: 도구 실행 순서를 알고리즘으로 최적화해 응답 속도와 비용을 함께
관리한다

- Atom 기반 Task DAG, 5개 알고리즘 비교(FIFO/HEFT/Branch-and-Bound/CP-SAT/포트폴리오)
- 벤치마크 수치 삽입

## Ⅵ. 활용방안 (3장)

### 슬라이드 15 — 기대 효과

**헤드라인**: 정확한 정보와 신뢰 가능한 판단은 청년의 의사결정 부담을 줄이고,

- KB 대출상품 DB 연동 → 자연스러운 상품 인지·가입 유입 채널

### 슬라이드 16 — 확장 로드맵

**헤드라인**: 팔달구 프로토타입에서 전국 서비스로 확장하는 다음 단계가 명확하다

- 실매물 확대, 실사고 라벨 확보, 전국 지역 외삽
- 우선순위별(최우선/모델/시스템) 로드맵

### 슬라이드 17 — 개발 현황

**헤드라인**: 지금 무엇이 되고, 무엇이 남았는지 투명하게 공개한다

- Now(완료) / Next(진행중) / Later(계획) 3단 구성
- 검증된 것 vs 검증되지 않은 것 표(연구논문 20장 내용 재사용 가능)
