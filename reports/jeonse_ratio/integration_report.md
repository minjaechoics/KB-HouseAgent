# 다가구 전세가율 확률분포 통합 보고서

## 구현

`src/jeonse_ratio`는 기존 선순위 보증금 모델과 건물가치 모델의 분위수
출력을 결합하는 독립 계층이다. 기존 모델을 재학습하거나 계수를 바꾸지
않는다.

1. 입력을 만원 단위 공통 계약으로 정규화한다.
2. 원시 표본이 없으므로 P05/P10/P50/P90/P95에서 piecewise-linear
   inverse CDF로 각각의 분포를 복원한다.
3. 기본은 독립 표본이며 Gaussian copula ρ=0.2/0.4/0.6을 민감도로 계산한다.
4. 내 보증금은 고정값 또는 삼각분포로 결합한다.
5. 기본 20,000개 경로에서 분위수와 60/70/80/90/100% 초과확률을 계산한다.
6. 시장가치 -5/-10/-20/-30% 스트레스를 계산한다.

비율은 100%에서 자르지 않는다.

## 운영 위험구간

- P50 ≤ 60%: 안전
- 60% < P50 < 70%: 관찰
- 70% ≤ P50 < 80%: 주의
- P50 ≥ 80%: 위험

이는 비교 설명용 운영 경계이며 법적 보장 기준이 아니다. UI는 P10~P90과
80%·100% 초과확률을 함께 표시한다.

## 보증과 법정 보호

보증상품 DB는 금융상품 DB와 분리했다. HUG·HF·SGI 결과는 가입 확정이
아닌 사전검토다. 수원 최우선변제도 금액 외에 담보권 설정일, 인도,
주민등록, 다가구 전체 소액임차인 안분 한도를 확인해야 한다.

공식 근거:

- HF: https://hf.go.kr/ko/sub02/sub02_05_01.do
