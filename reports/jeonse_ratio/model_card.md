# Model Card — Multifamily Jeonse Ratio Integration v1

## Intended use

수원시 다가구 전세 후보의 계약 후 보증금 회수 위험을 비교하고 계약 전에
추가 확인할 매물을 선별하는 의사결정 보조 모델이다.

## Not intended use

- 법률의견 또는 보증 가입 확정
- 등기부·전입세대확인서·확정일자부의 대체
- 특정 임대인의 실제 재산·체납 확정
- 대출 승인 또는 감정평가 대체

## 구성

- 기존 임차보증금·선순위 보증금 분포 모델
- RTMS 매매와 건축물 특성 기반 건물 시장가치 분포
- 분위수 분포복원, Monte Carlo 결합
- Gaussian copula 의존성 민감도

통합 계층 자체는 지도학습 모델이 아니므로 training loss가 없다.

## 한계

1. 같은 건물의 실제 전체 임대차계약 라벨이 없다.
2. 두 입력 모델의 paired residual이 없어 기본적으로 독립을 가정한다.
3. 원시 draw가 아니라 분위수에서 분포를 복원한다.
4. 건물가치가 감정평가 또는 현재 실거래 확정값이 아니다.
5. 근저당·압류·신탁·체납은 별도 공식 확인 대상이다.

입력 품질이 높아도 통합 결과 품질은 최소 한 단계 낮춘다.

## 평가

`tests/test_jeonse_ratio.py`의 20개 테스트는 단위, 건물 ID, 기준일,
가격기준, 분위수 역전, 꼬리, 네 비율 정의, 100% 비절단, 임계값 단조성,
seed 재현성, 의존성, 스트레스, 보증 사전검토를 검증한다.
