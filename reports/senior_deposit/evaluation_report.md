# 선순위 임차보증금 모델 평가 보고서

## 1. 평가 가능한 부분

보증금 Model C는 실제 RTMS로 평가했다.

| 항목 | 결과 |
|---|---:|
| train / validation / test | 7,441 / 15,526 / 11,128 |
| 유효 test 계약 | 11,100 |
| 중앙 절대오차 | 355.58만원 |
| 중앙 절대백분율오차 | 28.48% |
| 50% 구간 coverage | 49.06% |
| 80% 구간 coverage | 78.21% |
| 90% 구간 coverage | 88.26% |

validation split-conformal 보정 후 validation coverage는 각각 50.01%, 80.01%,
90.01%였다. test에서 90% 구간은 88.26%로 다소 과소 coverage다.

## 2. 평가할 수 없는 부분

현재 점유, 개별 임차인의 법적 선순위, 건물 단위 실제 선순위 총액 라벨이
0건이다. 따라서 다음 수치를 보고하지 않는다.

- 점유 호실 MAE·Beta-Binomial NLL
- 선순위 ROC-AUC·PR-AUC·Brier score·ECE
- 최종 선순위 총액 MAE·coverage
- conservative p95의 실제값 포착률

이 값들을 합성 라벨로 채우지 않는다.

## 3. 실제 end-to-end 예시

건물 `HUB-8afd698677db742af7bb`, 공부상 13호, 대상 1호 제외, baseline
occupancy, conservative 선순위, 20,000회:

| 출력 | 결과 |
|---|---:|
| 다른 점유 호실 p10/p50/p90 | 9 / 11 / 12호 |
| 보수적 총액 p50 | 826,660,922원 |
| 보수적 총액 p90 | 1,043,380,818원 |
| 보수적 총액 p95 | 1,107,067,522원 |
| 10억원 초과 확률 | 15.05% |
| 데이터 품질 | medium |
| 로컬 CLI 시간 | 약 12.2초 |

이 숫자는 법적 선순위 확정액이 아니라 Model B 시나리오와 Model C 실제
보증금 분포를 결합한 보수적 추정이다. 기준일 이전 동일 법정동의 최신
집계월 2026-06을 사용했다.
