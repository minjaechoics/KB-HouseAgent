# 전세금/집주인 총자산 비율 모델 평가 보고서

평가 기준일은 2026-07-28이다. 아래 수치는 합성 smoke 결과가 아니라 실제
건축HUB, 국토교통부 실거래가, 가계금융복지조사 공개용 마이크로데이터로
학습한 `owner_asset_ratio_actual.joblib`의 결과다.

## 1. 실제 데이터

| 데이터 | 원본 행 | 모델 사용 방식 |
|---|---:|---|
| 수원 건축HUB 표제부·층별개요 | 9,482 | 공부상 호실과 건물 특성 |

| 가계금융복지조사 2022~2025 | 73,026 | 임대인 모집단 prior |
| 조사자료 중 임대인 필터 통과 | 9,371 | `K_other`, `R_survey`, `L_debt` |

## 2. 데이터 분리

- 건축물: train 3,859 / validation 830 / test 1,758
- 임대차: train 7,441 / validation 15,526 / test 11,128
- 매매 직접 라벨: train 104 / validation 22 / test 47
- 조사 임대인: 2022~2023 train 4,506 / 2024 validation 2,397 /
  2025 test 2,468

- 계약 시점 지역 집계는 `shift(1)` 후 rolling해 미래 계약을 보지 않는다.

## 4. 집주인 기타자산 prior와 보정

`K_other=(총자산-임대용 부동산자산)/임대용 부동산자산`은 조사 가중 경험분포로
학습했다. 2024년 validation에서 `K` scale 0.975를 선택했고, 2025년
held-out 모집단 분위수 손실은 0.00693이었다.

이는 **개별 집주인 자산 정답에 대한 오차가 아니다.** 조사 모집단의
`임대보증금 부채/총자산` 분포를 재현하도록 한 post-hoc calibration이다.
개별 집주인 총자산 라벨이 없으므로 개인 단위 MAE는 의도적으로 보고하지 않는다.

## 5. 실제 end-to-end 예시

건축HUB 건물 `HUB-8afd698677db742af7bb`, seed 20260728, 20,000회:

| 출력 | p10 | p50 | p90 |
|---|---:|---:|---:|
| 추정 총보증금 | 43,248만원 | 72,337만원 | 116,546만원 |
| 추정 집주인 총자산 | 120,483만원 | 230,299만원 | 490,608만원 |
| 전세금/총자산 비율 | 0.13 | 0.30 | 0.70 |

- 비율 0.6 초과 확률: 15.04%
- 비율 0.8 초과 확률: 6.58%
- 비율 1.0 초과 확률: 2.78%
- 데이터 품질: high
- 20,000회 CLI 추론: 로컬 측정 약 19.9초

이 예시에서 분산 기여도가 큰 항목은 건물가치 52.45%, 보증금 분포
34.98%였다. 기여도는 ablation 기반 근사치이며 인과적 분해가 아니다.

## 7. 남은 한계

1. 특정 집주인의 실제 예금·주식·다른 부동산을 조회하지 않는다.
2. 대상 건물이 집주인의 임대용 부동산을 대표한다는 근사 가정이 있다.
3. 임대 활용률은 관측 라벨이 없어 Beta prior이며 저/기본/고 시나리오로
   민감도를 제공한다.
4. 공개 RTMS 일부 지번은 exact 건물 식별자가 아니다.
5. 실제 등기부·근저당·선순위 임차보증금 확인을 대체할 수 없다.
