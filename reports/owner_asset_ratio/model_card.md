# Model Card: Four-Component Owner Asset Ratio v1

## 목적

수원시 단독·다가구 건물에 대해 다음 조건부 확률분포를 추정한다.

`R = 추정 총 임대보증금 / 추정 집주인 총자산`

이 모델은 특정 집주인의 실제 재산을 조회하거나 맞히는 모델이 아니다.

## 모델 구조

1. 공부상 호실 수: 관측 우선, 결측일 때 Negative Binomial/Poisson 후보 비교
2. 호실별 보증금: `log1p(deposit)` 다중 분위수 회귀
3. 건물 시장가치: `log1p(sale_price)` 다중 분위수 회귀
4. 기타 자산비율 `K`: 가계금융복지조사 표본가중 경험분포와 계층 fallback
5. 위 네 분포를 독립 학습한 후 기본 20,000회 Monte Carlo에서 결합

## 의도된 사용

- 등기부·세입자 현황·집주인 동의 자산증빙을 확인하기 전의 사전 불확실성 안내
- 추가 서류 확인 우선순위 결정
- `K=0`, 조건부 prior, 높은 완충 시나리오 비교

## 금지된 사용

- 실제 집주인 총자산 또는 순자산의 확정값으로 표시
- 대출·보증·계약 승인/거절의 단독 근거
- 합성 smoke artifact를 사용자 위험도에 사용
- 단독·다가구 일부 지번을 확정 건물로 연결
- 개별 건물과 가계금융복지조사 행을 직접 결합

## 데이터 분리

- 계약자료는 가능한 연월 기준으로 train/validation/test를 분리하고 마지막
  기간을 test로 둔다.
- 공간: 법정동 약 20%를 개발 자료에서 완전히 제외해 spatial test에 포함한다.
- 조사: 2022~2023 train, 2024 validation, 2025 test로 분리하고
  표본가중치를 유지한다.

## 불확실성

가장 큰 불확실성은 관측되지 않은 집주인의 기타 자산 `K`와 실제 임대 활용률이다.
출력에는 입력별 ablation 분산 감소량, occupancy 저/기본/고 시나리오,
건물 랜덤효과 시나리오를 포함한다.

## 현재 artifact 상태

- `owner_asset_ratio_synthetic_smoke.joblib`: 파이프라인 실행 검증 전용
- `owner_asset_ratio_actual.joblib`: 실제 건축HUB 9,482건, 임대차 34,095건,
  매매 1,697건, 조사 임대인 9,371건으로 2026-07-28 학습 완료
- API는 actual artifact만 로드하며 synthetic artifact를 거부한다.

## 평가 제한

개별 집주인 실제 총자산 라벨이 없으므로 개별 MAE를 보고하지 않는다. 실제
평가는 조사 가중 모집단 calibration, 분위수 coverage, 공간·시간 holdout을
사용한다. 건물가치 test 직접 라벨은 47건으로 작으므로 결과를 탐색적 초기치로
본다. 지역 보증사고율과의 순위상관 및 정성적 경매 표본 검증은 아직 완료되지
않았다.

## 필수 경고

> 이 값은 특정 집주인의 실제 금융·부동산 자산을 조회한 결과가 아니다.
> 대상 건물의 추정 보증금·가치와 임대인 가구의 통계적 자산분포를 결합한
> 확률적 추정치다.
